# Module Name: Python Fundamentals

Establish Python as a confident, everyday tool for scripting and automation.

## Features
- **Language Basics**: Thorough coverage of Python core syntax and types.
- **Standard Library**: Exploration of essential modules for real-world tasks.
- **Mini Projects**: Practical applications of fundamentals.

## Learning Objectives
- Implement complex logic without relying on third-party magic.
- Understand the underlying mechanics of Python 3.10+ features.
- Analyze performance characteristics using real-world benchmarks.

## Project Structure
- `basics/`: Core language features scripts.
- `stdlib/`: Essential standard library modules demonstrations.
- `projects/`: Practical CLI tools and utilities.

## Requirements
- Python 3.10+

## How to Run
Run any script directly using python:
```bash
python basics/01_types_and_variables.py
```

## Testing
Run tests using the built-in unittest module or pytest:
```bash
pytest
```
