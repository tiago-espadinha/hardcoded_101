IntersectionObserver

Scroll visibility detected without scroll event listeners. Elements are unobserved after triggering for zero ongoing overhead.

Lerp Interpolation

The cursor follow effect uses linear interpolation in a requestAnimationFrame loop — the foundation of smooth procedural motion.

🎨

CSS clip-path Morphing

Four blobs morph between polygon shapes using pure CSS keyframes. Each runs on a different duration to avoid synchronisation artifacts.

✏️

SVG Path Drawing

A circuit-board SVG draws itself via stroke-dashoffset transitions, sequenced with per-element transition-delay.

🌐

Canvas Particle System

80 particles rendered in Canvas 2D, connected by proximity lines and repelled by the cursor — within a strict 4ms per-frame budget.

Technique 03

Self-drawing SVG

Every path animates from stroke-dashoffset equal to its own length down to zero, creating the illusion of being drawn in real time.

Technique 04
