# Design Tokens

Aurora DS uses a **two-layer token architecture**: primitive tokens define the raw values, semantic tokens reference primitives and give them meaning.

## Layer 1 — Primitive Tokens

Raw values without context. Never use these directly in components.

## Using Tokens in Components

```tsx
// CSS custom property (recommended)
<div style={{ color: 'var(--aurora-color-foreground-default)' }} />

// Tailwind (via aurora- prefix)
<div className="text-aurora-foreground-default bg-aurora-background-subtle" />

// TypeScript constant reference
import { TOKEN } from '@aurora-ds/tokens';
const color = TOKEN.color.brand.default; // 'var(--aurora-color-brand-default)'
```
