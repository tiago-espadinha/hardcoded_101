# Module Name: Personal Portfolio Site

A visually appealing, responsive personal developer portfolio website built from scratch using fundamental web technologies.

## Features
- **Responsive Design**: Fluid layout using CSS Grid and Flexbox that works seamlessly on mobile, tablet, and desktop.
- **Dark/Light Mode**: User-selectable theme with persistence using localStorage and support for system preferences.
- **Interactive Animations**: Smooth scroll effects, IntersectionObserver-based reveals, and a custom typing effect for the hero section.
- **Client-Side Validation**: Robust contact form with real-time feedback and accessibility features.

## Learning Objectives
- Implement complex logic without relying on third-party magic.
- Understand the underlying mechanics of CSS custom properties, IntersectionObserver, and modern DOM APIs.
- Analyze performance characteristics using real-world benchmarks and Lighthouse.

## Project Structure
- `index.html`: The main structural skeleton of the site.
- `css/`: Modular CSS files (variables, layout, components, animations, reset).
- `js/`: Modular JavaScript files (theme, navigation, typing, scroll, form).
- `assets/`: Icons and other static assets.

## Requirements
- Modern Web Browser (Chrome, Firefox, Safari, Edge)
- No build tools required — just open `index.html`.

## How to Run
Simply open the `index.html` file in any modern web browser to view the portfolio.

## Testing
This project is built using static files and can be tested for accessibility and performance using Chrome DevTools Lighthouse.
