# Module Name: Vanilla JS Todo & Notes App

A full-featured Todo and Notes application built with pure Vanilla JavaScript, exploring the MVC pattern and manual DOM manipulation.

## Features
- **Strict MVC Architecture**: Decoupled models, views, and controllers for clean state management.
- **Advanced Todos**: Drag-and-drop reordering, inline editing, and smart filters.
- **Persistent Notes**: Auto-saving to localStorage with debounced updates, pinning, and tagging.
- **Responsive UI**: Two-panel layout with dark/light mode and smooth transitions.

## Learning Objectives
- Master event delegation and manual DOM reconciliation.
- Understand the benefits of the MVC pattern in frontend development.
- Implement complex browser APIs like Drag & Drop and LocalStorage.

## Project Structure
- `js/models/`: Business logic and data structures.
- `js/views/`: Pure DOM rendering functions.
- `js/controllers/`: Event handling and orchestration.
- `css/`: Modular styles (reset, layout, components, animations).

## Requirements
- A modern web browser (supporting ES2022).

## How to Run
Open `index.html` in any modern browser.

## Testing
Manual verification of all UI components and persistence logic.
